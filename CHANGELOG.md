# Ludolume changelog

Selected meaningful, user-facing updates, newest first. Release dates follow the published GitHub releases.

## Unreleased

Changes since v0.6.0-alpha; public availability depends on rollout.

### Added

- Three Bosses mobile play with touch controls.
- Optional remembered sign-in and self-service account deletion, where enabled.
- A privacy notice and controls for optional public leaderboard participation, including removing public entries while keeping private scores, where enabled.

### Changed

- P4-Vega runs now finish at 1,000 points, warn before new hazards become dangerous, and support pause and resume.
- Expanded English and Portuguese privacy information for parent-led accounts, optional daily limits, inactivity warnings and data retention, pending rollout.

### Fixed

- Phone layouts and fullscreen rotation, including more readable mobile leaderboards.
- Failed music uploads in Dancing Circles and Dancing Fractals now show errors and allow retrying the same file.

## [v0.6.0-alpha](https://github.com/Good-Loops/mickeyf.com/releases/tag/v0.6.0-alpha) — 2026-09-01

### Added

- Three Bosses for desktop browsers, with a pause menu, ranks, and personal-best submissions.
- A leaderboard hub with separate standings for each game.
- P4-Vega touch controls with a choice of left- or right-handed fullscreen joystick.

### Changed

- Redesigned the site with a deep-space glass theme and responsive game and animation controls.

### Fixed

- Three Bosses startup failures on first load and gameplay continuing while the browser is in the background.

## [v0.5.0-alpha](https://github.com/Good-Loops/mickeyf.com/releases/tag/v0.5.0-alpha) — 2026-01-20

### Added

- Dancing Fractals: music-responsive Tree, Flower Spiral, and Mandelbrot animations, with an automated Mandelbrot tour.

## [v0.4.0-alpha](https://github.com/Good-Loops/mickeyf.com/releases/tag/v0.4.0-alpha) — 2024-06-29

### Added

- P4-Vega background music and musical notes, with selectable keys and major, minor, or pentatonic scales.

## [v0.3.0-alpha](https://github.com/Good-Loops/mickeyf.com/releases/tag/v0.3.0-alpha) — 2024-06-01

### Added

- Sign-in and sign-out, saved P4-Vega personal bests, and a leaderboard.

## [v0.2.33-alpha](https://github.com/Good-Loops/mickeyf.com/releases/tag/v0.2.33-alpha) — 2024-05-10

### Added

- Initial release with Dancing Circles, P4-Vega, account registration, and responsive navigation.
