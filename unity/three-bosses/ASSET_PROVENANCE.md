## Original replacement assets

The following paths now contain locally generated replacements:

- `Assets/Sprites/UI/Vignette.png` — an original mathematical radial-gradient
  utility texture containing none of the previously used PNGAll image data.
- `Assets/Sprites/UI/Square.png` — an original solid-color utility texture
  containing none of the previously used Unity package image data.

Their existing Unity `.meta` GUIDs were retained solely to preserve project
references.
